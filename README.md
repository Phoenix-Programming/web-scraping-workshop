# Web Scraping Workshop
[Link to original workshop this is based on](https://github.com/gerzytet/web-scraping-workshop-files).

A beginner programming workshop for automating data collection from static websites using Python and BeautifulSoup. Scrape data from a Pokémon website to make a "Who's that Pokémon?" quiz.

This repository contains the final code that was discussed in detail during the workshop.
